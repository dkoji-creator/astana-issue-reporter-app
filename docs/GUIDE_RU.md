# Гид по коду (для защиты)

Коротко: приложение на телефоне (папка `mobile/`) ничего не хранит само. Оно отправляет запросы на сервер (папка `backend/`), а сервер читает и пишет в базу PostgreSQL. Это та самая трёхуровневая архитектура из C1 мид-проекта.

```
Телефон (mobile/)  →  HTTPS-запрос  →  Сервер (backend/)  →  PostgreSQL
                                             └→ хранилище фото (Supabase Storage)
```

Если вы знаете Python, читайте так: `async/await` — то же, что в Python; `const x = ...` — переменная; `(a) => a + 1` — это `lambda a: a + 1`; `{ ...obj, key: 1 }` — копия словаря с изменённым ключом.

## Как проходит одна заявка (C4 Data Flow)

1. Житель нажимает «+», телефон открывает камеру. Фото сжимается (`lib/photo.js`).
2. GPS ставит метку, житель выбирает категорию, пишет описание, нажимает «Отправить».
3. `lib/api.js` отправляет фото и данные на сервер по HTTPS.
4. Сервер (`routes/reports.js`) проверяет вход, фото, текст, координаты. Фото уходит в Supabase Storage, а ссылка на него и остальные данные записываются в таблицу `reports`.
5. Заявка сразу появляется на карте у всех.
6. Админ меняет статус (`routes/admin.js`), сервер пишет историю и уведомление. Через ≤ 30 секунд у автора появляется уведомление на телефоне.

## Вопросы, которые могут задать

- **Почему PostgreSQL, а не SQLite, как в Assignment 3?** SQLite — это файл на одном компьютере, для облачного сервера, к которому одновременно подключается много телефонов, он не подходит. PostgreSQL мы и планировали в C2 мид-проекта.
- **Как хранятся пароли?** Только хеш PBKDF2 с солью (`passwords.js`), сам пароль нигде не сохраняется. Проверить можно в Supabase → Table Editor → users.
- **Можно ли лайкнуть дважды?** Нет: в таблице `votes` первичный ключ (user_id, report_id), база не даст создать вторую строку.
- **Почему не Firebase Storage?** Firebase теперь требует платный тариф с картой; Supabase бесплатен и хранит базу и фото в одном месте.
- **Почему сервер иногда отвечает долго?** Бесплатный Render засыпает после 15 минут простоя, первый запрос будит его до минуты. Перед защитой откройте приложение заранее.
